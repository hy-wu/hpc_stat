# 研究方法 / Methodology

**研究问题**：跨 GPT 模型版本的传统语义理解、抽象推理与长上下文能力，是否在 Agent、设计或成本优化的同时发生退化？

## 数据层级
- A：可重复、固定版本与 harness、含样本量、独立或透明原始结果和置信区间。
- B：可追溯的公开独立榜单或厂商指标（动态页面/选择性披露），尚不满足 A 的复现要求。
- C：可回溯至原帖的真实用户经验事件；只反映个案与失败模式，不估计群体比例。
- D：待采集的来源入口，尚无匹配该模型版本与配置的数据。

**证据等级属于来源与记录，不等同于所声称因果机制的可信度**。每项结果包含 source ID、suite、metric、unit、status、必要时 effort。

## 比较准则
1. 只在同评测版本、同任务、同采样/推理预算、同环境与工具权限下计算直接差值。
2. 不把 LiveBench、Artificial Analysis、Arena、SWE-bench 与厂商内部 benchmark 指标加权成一个“智力总分”。
3. 缺失值留空，跨版本旧型号通常无相同 harness 数据，不做线性插值。
4. 热力颜色只在**同一数值列**内相对归一化，反向指标（例如幻觉率）反转颜色，不解释为跨维度尺度。
5. 对动态排行榜保留抓取日期、过滤器、模型 ID、推理档位、是否 API/ChatGPT 路由。当前 2026-11-19 快照存在待核验项，UI 标注 research seed。
6. 用户反馈按任务/模型/正负性标注，同时保留出处；不得将少量帖子推断为“多数用户”。
7. 经济性必须区分 `USD/1M tokens` 标价、在指定 token 情境下计算的 API 成本和重复试错后每个正确结果的真实成本。

## 假说
- H1: 5.6 Luna ≈ 6.1 Terra ≈ 6.2 Sol
- H2: 5.6 Terra ≈ 6.1 Sol ≈ 6.2 Astra
- H3: 5.6 Sol ≈ 6 Astra ≈ 未公布的更高档位

这只是用户体验驱动的**等能力线候选**，不是已知模型谱系；“Bel”没有经公开确认的型号证据。

## 对照实验
设计独立盲测题集（语义歧义、隐含约束、反事实推理、长上下文逻辑冲突、开放概念构建）。对各模型执行 n≥3 重复，统一无工具和推理强度。采用人工匿名评分与可验证子题双轨；记录版本 ID、时间、请求参数、token、延迟、成本、模型输出及失败类型。对成对模型报告 bootstrap CI、效应量与任务级差异分布，而不是单一主观评分。

## 质量控制与已知不足
- 本研究包的 46 条指标与价格来自 2026-11-19 研究种子，部分动态快照未逐行复核，因此标记 `snapshot-needs-recheck`。
- 用户反馈条目为摘要而非原文引用；保留原帖供审查。
- 价格不包括重试、隐藏推理开销或代理环境，图中的质量与价格不是纯语言智能的 Pareto 真值。
- 对 LiveBench 历史版本日期、不同网站的评测版本识别等应进一步核实。
- 当前不作“GPT-6 系列系统性退化”这一因果性结论。
